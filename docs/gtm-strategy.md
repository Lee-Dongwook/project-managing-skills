# GTM (GO-TO-Market) 전략

신제품이나 서비스를 시장에 성공적으로 출시하고 판매하기 위한 종합 실행 계획.

### 1. 타켓 고객(ICP)정의

ICP(Ideal Customer Profile)는 우리 제품을 구매할 가능성이 높고, 구매 후에도 지속적으로 가치를 얻을 고객군을 정의하는 과정이다.

| 정의 항목       | 구체적 질문                                                |
| --------------- | ---------------------------------------------------------- |
| 산업, 시장      | 어떤 산업과 시장을 공략할 것인가?                          |
| 기업 규모       | 직원 수, 매출, 조직 구조는 어떠한가?                       |
| 핵심 페르소나   | 실제 사용자, 구매 결정권자, 예산 승인자는 누구인가?        |
| 핵심 Pain Point | 어떤 업무가 느리거나, 비싸거나, 반복적인가?                |
| 구매 계기       | 어떤 사건이나 목표 때문에 지금 구매를 하려고 하는가?       |
| 현재 대안       | 엑셀, 기존 SaaS, 자체 개발, 수작업 중 무엇을 사용하는가?   |
| 지불 의사       | 문제 해결에 얼마까지 지불할 의사가 있는가?                 |
| 제외 조건       | 어떤 고객은 도입 비용이나 요구사항 때문에 적합하지 않은가? |

#### 산출물

- ICP 정의서
- 고객 페르소나
- 고객 문제 및 구매 동기 목록
- 초기 공략 고객 세그먼트 우선순위
- 고객 인터뷰 및 시장 검증 계획

---

### 2. 고유 가치 제안 (UVP)

UVP(Unique Value Proposition)는 고객이 우리 제품을 선택해야 하는 이유를 명확하게 표현하는 것이다.

- Customer Problem: 고객이 해결하려는 문제

- Value Proposition: 제품이 제공하는 구체적인 가치

- Differentiation: 경쟁사나 기존 대안과의 차이

- Positioning: 고객의 머릿속에서 차지하려는 제품의 위치

- Proof: 그 가치가 실제로 존재한다는 근거

- Messaging: 웹사이트, 광고, 영업 자료에서 전달할 핵심 메시지

#### 산출물

UVP 문장, 경쟁사 비교표, 메시지 매트릭스, 랜딩 페이지 핵심 카피.

---

### 3. 가격 및 수익 모델 설정

고객이 인식하는 가치, 대안의 가격, 구매 방식, 제공 비용을 함께 고려해야 한다.

| 모델           | 적합한 제품 유형       | 주요 고려 사항                   |
| -------------- | ---------------------- | -------------------------------- |
| 구독형         | SaaS, 협업 도구        | 월간,연간 계약, 해지율           |
| 사용량 기반    | API, AI 서비스         | 사용량 측정, 비용 변동           |
| 사용자당 과금  | 협업 업무 관리 SaaS    | 사용자 증가와 매출의 관계        |
| 성과 기반      | 리드 생성, 광고 최적화 | 성과 측정과 귀속 기준            |
| 구축, 라이선스 | 엔터프라이즈 솔루션    | 초기 구축비, 유지보수, 계약 규모 |
| Freemium       | 셀프 서비스 SaaS       | 무료에서 유료로의 전환율         |

#### 주요 확인 포인트

- 고객이 어떤 단위의 가치를 얻는가?

- 그 가치는 고객 규모나 사용량에 따라 어떻게 달라지는가?

- 무료 체험, 파일럿, 유료 PoC 중 어떤 방식으로 진입 장벽을 낮출 것인가?

- 고객 획득 비용(CAC)과 고객 생애 가치(LTV)가 지속 가능한가?

- 할인과 연간 계약이 수익성 및 고객 유지율에 미치는 영향은 무엇인가?

#### 산출물

- 가격 정책표 (플랜별 기능, 가격, 제한 사항)
- 단위 경제성(Unit Economics) 시뮬레이션
- 할인 및 계약 조건 가이드

---

### 4. 판매 / 마케팅 채널의 정합성

ICP가 정보를 탐색하고 구매를 결정하는 방식과, 제품의 가격대 및 복잡도에 맞는 채널을 선택해야 한다.

| 성장 방식                | 적합한 상황                        | 주요 채널                           | 주요 고려 사항                     |
| ------------------------ | ---------------------------------- | ----------------------------------- | ---------------------------------- |
| PLG (Product-Led Growth) | 저가, 셀프 온보딩이 가능한 제품    | 무료 체험, Freemium, 제품 내 바이럴 | 활성화율, 무료에서 유료로의 전환율 |
| 인바운드 마케팅          | 고객이 직접 문제 해결책을 검색     | SEO, 콘텐츠, 웨비나, 커뮤니티       | 콘텐츠 축적 기간, 리드 품질        |
| 아웃바운드 영업          | 명확한 타겟 기업 리스트가 있음     | 콜드 메일, 링크드인, 전화           | 응답률, 영업 인력 비용             |
| 세일즈 주도 (Sales-Led)  | 고가, 구매 결정 과정이 복잡한 제품 | 영업 미팅, 데모, PoC                | 영업 사이클 길이, 계약 규모        |
| 파트너, 리셀러           | 기존 유통망이나 고객 기반 활용     | SI, 총판, 마켓플레이스, 제휴사      | 수수료 구조, 파트너 교육           |
| 유료 광고                | 빠른 검증과 수요 확인이 필요       | 검색 광고, SNS 광고, 리타겟팅       | CAC, 광고 효율(ROAS)               |

#### 주요 확인 포인트

- 고객은 어디서 문제를 인식하고, 어디서 해결책을 탐색하는가?

- 제품 가격(ACV)이 해당 채널의 획득 비용을 감당할 수 있는가?

- 마케팅에서 영업으로 리드를 넘기는 기준(MQL, SQL)이 정의되어 있는가?

- 초기에는 1~2개 채널에 집중하고 있는가?

#### 산출물

- 채널 우선순위 및 예산 배분안
- 고객 구매 여정(Customer Journey) 맵
- 세일즈 퍼널 및 리드 전환 기준
- 영업 자료 (소개서, 데모 시나리오, FAQ)

### 5. 출시 실행 계획

출시 전후로 해야 할 일을 단계별로 나누고, 각 단계의 목표와 담당자를 명확히 한다.

| 단계         | 목표                          | 주요 활동                                        |
| ------------ | ----------------------------- | ------------------------------------------------ |
| 출시 전 준비 | 시장 검증 및 내부 준비        | 베타 테스트, 레퍼런스 고객 확보, 내부 교육       |
| 소프트 런칭  | 소규모 고객 대상 반응 확인    | 대기자 명단 초대, 파일럿 운영, 피드백 수집       |
| 정식 출시    | 인지도 확보 및 초기 매출 발생 | 보도자료, 런칭 이벤트, 광고 집행, 영업 본격화    |
| 출시 후 개선 | 전환율 및 유지율 개선         | 데이터 분석, 메시지 및 가격 조정, 고객 사례 제작 |

#### 산출물

- 출시 일정표 및 R&R(역할과 책임)
- 출시 체크리스트
- 런칭 커뮤니케이션 계획

---

### 6. 성과 지표 (KPI)

GTM 전략이 실제로 작동하는지 확인하기 위해 퍼널 단계별 지표를 정의하고 정기적으로 점검한다.

| 구분       | 주요 지표                                      |
| ---------- | ---------------------------------------------- |
| 유입       | 방문자 수, 리드 수, 채널별 유입 비중           |
| 전환       | 리드 → 미팅 전환율, 체험 → 유료 전환율, 수주율 |
| 매출       | MRR/ARR, 평균 계약 규모(ACV), 영업 사이클      |
| 효율       | CAC, LTV/CAC 비율, CAC 회수 기간               |
| 유지, 확장 | 해지율(Churn), 순매출 유지율(NRR), 업셀 비율   |

#### 산출물

- KPI 대시보드
- 주간, 월간 성과 리뷰 프로세스
