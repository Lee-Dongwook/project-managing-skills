# ICP 및 페르소나

> 상태: 초안 (전부 미검증 가설) · 최종 수정: 2026-10-21
> 인터뷰 결과에 따라 "근거 / 검증 상태" 열을 채우고, 기각된 가설은 [experiment-log.md](experiment-log.md)에 남긴다.

## 1. 첫 공략 고객군 (ICP)

**한 줄 정의**: ERP는 있지만 발주량 결정은 엑셀과 담당자 경험에 의존하는 국내 중소 제조기업

| 항목            | 가설                                                                                         | 근거 / 검증 상태 |
| --------------- | -------------------------------------------------------------------------------------------- | ---------------- |
| 산업, 시장      | 국내 중소 제조업 (부품·소재 가공, 다품종 소량 생산)                                          | 미검증           |
| 기업 규모       | 직원 50~300명, 구매·자재 담당 1~5명, 관리 품목 수백~수천 개                                  | 미검증           |
| 핵심 Pain Point | 발주량을 엑셀과 경험으로 정해서 결품(긴급 발주)과 과잉 재고가 반복된다                       | 미검증           |
| 구매 계기       | 결품으로 인한 납기 지연·긴급 발주, 담당자 퇴사로 노하우 유실, 원자재 가격 급등               | 미검증           |
| 현재 대안       | 엑셀 + 담당자 경험. ERP의 MRP 기능은 있지만 안 쓰거나 신뢰하지 않음                          | 미검증           |
| 지불 의사       | 미확인. 긴급 발주·재고 비용 대비 얼마가 합리적인지 인터뷰에서 고객 발언으로만 확인           | 미확인           |
| 제외 조건       | 대기업(자체 SCM/APS 보유), 직원 20명 이하(발주 규모가 작음), 발주 데이터가 디지털화 안 된 곳 | 미검증           |

## 2. 페르소나

| 역할          | 직책 (가설)             | 관심사                              | 구매 과정에서의 역할          |
| ------------- | ----------------------- | ----------------------------------- | ----------------------------- |
| 실제 사용자   | 구매·자재 담당자        | 발주 판단 시간 단축, 결품 책임 회피 | 문제를 가장 잘 알고 도입 요청 |
| 구매 결정권자 | 구매팀장, 생산관리팀장  | 결품률·재고 금액 관리, 납기 준수    | 도입 여부 판단, 파일럿 승인   |
| 예산 승인자   | 대표, 공장장, 재무 담당 | 비용 대비 효과, 데이터 보안         | 최종 예산 승인                |

> 중소기업은 결정권자와 예산 승인자가 대표 한 명일 수 있다. 인터뷰에서 실제 결재 라인을 확인한다.

## 3. 문제 가설

| #   | 문제 가설                                                        | 검증 방법 (인터뷰 질문 연결)                | 상태   |
| --- | ---------------------------------------------------------------- | ------------------------------------------- | ------ |
| 1   | 발주량 결정에 주당 수 시간 이상의 수작업이 든다                  | 업무 흐름 설명 요청, 지난주 발주 과정 재현  | 미검증 |
| 2   | 결품으로 인한 긴급 발주가 월 1회 이상 발생한다                   | 최근 긴급 발주 사례와 빈도, 발생 비용       | 미검증 |
| 3   | 발주 노하우가 특정 담당자에게 묶여 있어 부재 시 업무가 멈춘다    | 담당자 휴가·퇴사 시 실제로 있었던 일        | 미검증 |
| 4   | ERP의 MRP 기능은 현장 상황(리드타임 변동 등)을 반영 못해 안 쓴다 | 현재 대안과 불편한 점, ERP를 쓰지 않는 이유 | 미검증 |

## 4. 초기 공략 세그먼트 우선순위

| 순위 | 세그먼트                                | 우선 이유 (가설)                       |
| ---- | --------------------------------------- | -------------------------------------- |
| 1    | 자동차·전자 부품 2·3차 협력사           | 원청 납기 압박이 강해 결품 비용이 크다 |
| 2    | 식품·소비재 제조 (유통기한 있는 원자재) | 과잉 재고가 곧 폐기 손실로 이어진다    |
| 3    | 기타 다품종 소량 가공업                 | 품목 수가 많아 수작업 부담이 크다      |
