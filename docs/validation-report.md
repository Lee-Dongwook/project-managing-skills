# GTM 검증 보고서

## 검증 지표

| 지표           | 목표      | 결과 | 해석 |
| -------------- | --------- | ---- | ---- |
| 인터뷰 완료    | 10건 이상 |      |      |
| 문제 반복 확인 | 5곳 이상  |      |      |
| 파일럿 제안    | 3곳 이상  |      |      |
| 유료 의사 검증 | 최소 1건  |      |      |

### 지표 해석 가이드

- 연락 응답이 적다 → 타깃 기업 선정, 메시지, 연락 채널 재검토
- 인터뷰는 잘되지만 문제 심각도가 낮다 → ICP 또는 문제 정의 변경
- 문제는 분명하지만 파일럿 반응이 없다 → 가격, 신뢰, 데이터 제공 부담, 구매 권한 조사
- 무료 파일럿 반응은 좋지만 유료 전환이 없다 → 지불 의사와 제품 가치 사이의 차이 검증

## 의사결정

- [ ] **진행 — MVP 개발**: 반복적인 문제와 구체적인 비용 확인 + 최소 1곳 이상 유료 파일럿 구매 행동
- [ ] **피벗 — 문제 또는 고객군 변경**: 문제는 분명하지만 방식·구매자·가격·도입 경로에 반응 없음
- [ ] **중단 또는 보류**: 충분한 검증에도 빈도·심각도·지불 의사 미확인
